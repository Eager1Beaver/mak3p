# Mak3P Changelog

## v1.0.0 - November 19, 2026

- Batch audio conversion to CBR MP3 with safe output naming.
- Content-based input detection, automatic sample-rate selection, and channel controls.
- Per-file bitrate matching, compatible metadata and artwork preservation.
- File/folder imports, drag-and-drop, parallel conversion, progress, and cancellation.
- Persistent settings and optional conversion logs.
